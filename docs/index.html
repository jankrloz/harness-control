Unified AI Coding Harness Control Plane

Audit installed skills across 18 AI coding harnesses, measure global and project token budgets, detect drift and duplicates, and resolve conflicts safely through package manager CLIs.

View on GitHub Download Desktop (macOS / Linux / Windows)

Core Capabilities

Multi-Harness & Profile Inventory

Scans Claude Code (~/.claude & ~/.claude-* profiles), Codex, Gemini CLI, Antigravity, OpenCode, Cursor, Windsurf, Kiro, and workspaces.

Global & Project Token Usage

Exact tiktoken counts (description, frontmatter, body, full) plus heaviest projects and session transcript activation tracking.

Drift & Duplicate Resolution

Flags global+project overlap, content divergence, relative age (older/newer/same), multi-manager conflicts, and cross-skill duplicates.

Manager-Only Execution

Delegates remove, upgrade, install, and migrate-to-apm strictly to apm, npx skills, claude plugin, and gemini extensions with dry-run previews.
